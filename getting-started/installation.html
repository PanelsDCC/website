Getting started with PanelsDCC

PanelsDCC is not a traditional desktop application, neither is it an iOS or Android app. Configuration is cloud based while control is local and accessible from any device with a web browser connected to PanelsDCC Control.

What you need

  • A Raspberry Pi on your layout, with PanelsDCC Control and PanelsDCC Connect installed.
  • A supported DCC command station, physically connected to the Raspberry Pi. Currently DCC-EX (via USB) and Hornby Elite (via USB) are known working. See Connecting your DCC controller/s for more information.
  • Your own devices – phones, tablets, laptops, desktops – with a modern web browser to connect to the Raspberry Pi over your network.
  • A PanelsDCC account so you can configure trains, accessories, and panels.

Step 1: Install PanelsDCC Connect and Control

Install both apps on your Raspberry Pi — either from a fresh OS image or on an existing Raspberry Pi OS system.

Prerequisites

  • Raspberry Pi 4 or later
  • 16 GB microSD card
  • PC with microSD reader (or adapter)

Option A: New SD card with Raspberry Pi Imager

Follow the standard Raspberry Pi Imager flow for the latest Raspberry Pi OS (64-bit). Choose Raspberry Pi OS (Desktop) if you plan to use a screen, keyboard, and mouse on the Pi.

In Imager, step by step:

  1. Open Raspberry Pi Imager.
  2. Choose your Raspberry Pi device.
  3. Choose the OS (64-bit; Desktop if you need a local GUI).
  4. Choose your SD card, then click Next.
  5. When asked about OS customisation, click Edit Settings.
  6. On the General tab, set hostname, username/password, Wi‑Fi, locale, and timezone.
  7. For hostname, we recommend panels-dcc so your URLs are easy to remember.
  8. On the Services tab, enable SSH if you want remote access (optional).
  9. On the Options tab (wording may vary), enable the first-boot command / run command field.
  10. Paste this into that field:
curl -fsSL https://panelsd.cc/install.sh | sudo bash
  1. Save settings and write the image to the card.
  2. Boot the Pi and wait a few minutes for first-boot install to finish.

When the install script completes, continue to Step 2.

Option B: Pi already running Raspberry Pi OS

If the Pi is already set up, install the latest PanelsDCC Connect and PanelsDCC Control with one command:

  1. Ensure the Pi has internet access.
  2. Open a terminal on the Pi (or SSH in).
  3. Run:
curl -fsSL https://panelsd.cc/install.sh | sudo bash

The script downloads and installs everything automatically. Then continue to Step 2.

Step 2: Post-install checks

Post-install: open in your browser

On a phone, laptop, or the Pi — stay on the same network as the Raspberry Pi. Confirm both Connect (port 9000) and Control (default port) load before continuing.

Use the same hostname as in Raspberry Pi Imager (we recommend panels-dcc). You can also enter a .local name or IP address. Your choice is saved in this browser.

PanelsDCC Connect port 9000

Wi‑Fi, DCC hardware, controller connections.

http://panels-dcc:9000/

Open Connect
PanelsDCC Control port 80 (default)

Run trains and panels in the browser — no port in the URL.

http://panels-dcc/

Open Control

Once that works, continue to Configure Wi‑Fi, then the manual getting-started path (controllers, first train, your PanelsDCC account). When that checklist is complete, move on to Chapter 2 — Configuration for cloud layout design.

Step 3: Using the Pi directly (optional)

If you prefer not to use another device on the network, you can run everything on the Pi itself.

  • Connect a screen, keyboard, and mouse to the Pi.
  • After install, use the desktop shortcuts for PanelsDCC Connect and PanelsDCC Control.

That is especially useful for changing network setup in Connect (for example switching between home Wi‑Fi and hotspot mode).
