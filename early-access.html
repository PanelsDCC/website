Early Access Programme

PanelsDCC is in active development. The early access programme is for hobbyists and clubs who are happy to run pre-release software and help shape how PanelsDCC evolves.

There are two phases: first, proving PanelsDCC Connect with a wide range of DCC controllers; second, exercising PanelsDCC Design + Control on real layouts.

We’re particularly interested in people with different DCC command stations who can help validate controller compatibility and real-world operation.

Phase 1 – Controller Compatibility (PanelsDCC Connect)

Goal: Prove PanelsDCC Connect works reliably with a wide range of DCC controllers, beyond the Hornby Elite used for initial development.

What you do: Install a pre-release image on a Raspberry Pi, plug it into your controller, and run a small set of tests to drive a locomotive and toggle a few accessories. You don’t need to test the full application yet.

Ideal for: Hobbyists and clubs with different command stations who are happy to run early software and send logs and feedback.

Phase 2 – Operating Beta (PanelsDCC Control + Connect)

Goal: Test PanelsDCC Control as a digital signal box for real layouts – including multi-device, multi-operator sessions.

What you do: Use PanelsDCC Control on a Raspberry Pi to run a simple but real layout, from phones, tablets, and big screens. Share feedback on responsiveness, multi-operator behaviour, and offline use at club nights or exhibitions.

How to Register Your Interest

If you’d like to join any of these phases, please register your interest. We’ll prioritise early access based on controller diversity, layout type, and willingness to provide feedback.
