Phase 1 – Controller Compatibility (PanelsDCC Connect)

Phase 1 of the early access programme is about answering a practical question: “Does PanelsDCC Connect work reliably with your command station?”

In this phase we focus on the hardware link only – making sure a Raspberry Pi running PanelsDCC Connect can talk cleanly to a range of DCC command stations, starting from the Hornby Elite and expanding to other systems.

Under the hood, PanelsDCC Connect uses an open‑source controller layer built on top of JMRI, which wraps JMRI’s mature controller support behind a simpler, DCC‑focused API, in line with JMRI’s licensing requirements.

What we are testing in Phase 1

The goal of this phase is to answer a simple question: “Can PanelsDCC Connect drive trains and accessories on your controller, reliably, for real layouts?”

For each controller we want to:

  • Detect and connect to the command station from a Raspberry Pi.
  • Control at least one locomotive (speed, direction, basic functions).
  • Toggle a handful of accessories (points, signals, etc.).
  • Confirm that the connection stays stable over a typical running session.

We’re not asking you to test the full PanelsDCC application yet – Phase 1 is focused solely on the reliability of the hardware link provided by PanelsDCC Connect.

How you can contribute

If you have a supported (or likely‑to‑be‑supported) DCC command station and a Raspberry Pi, you can help by:

  • Registering your interest via the early access page so we know which controller(s) you have.
  • Installing a pre‑release PanelsDCC Connect image on a Raspberry Pi and wiring it to your command station.
  • Running a small test script to drive a locomotive and toggle a few accessories.
  • Sending back logs and observations – especially if anything is unreliable, laggy, or surprising.

You don’t need to dive into the internals of JMRI or the underlying controller layer – the aim is to provide a simple “does it work on my controller?” check from a normal user’s point of view.

To take part or offer hardware for testing, please email hello@panelsd.cc with:

  • Which command station(s) you have, including exact model names.
  • Which PC interface(s) you can use or lend (USB, serial, Ethernet, etc.).
  • Whether you want to run tests yourself, lend hardware, or both.
