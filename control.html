PanelsDCC Control

Once Connect is working with your command station, use PanelsDCC Control to run your layout from any browser on your network.

If you used hostname panels-dcc, open:

http://panels-dcc/

Otherwise use http://<hostname>/ (same hostname as Connect, without the port).

Best on mobile and tablet: install as a PWA

Before going further, if you use PanelsDCC Control on a phone or tablet, it is best to install it as a Progressive Web App (PWA).

A PWA is a website that can be added to your home screen and launched like a normal app, with full-screen behavior and quick access.

iPhone / iPad (Safari): open PanelsDCC Control, tap Share, tap Add to Home Screen, then tap Add.

Android (Chrome): open PanelsDCC Control, tap the menu (...), then tap Install app or Add to Home screen.

Launch it from your home screen, then continue.

First launch and login

When you first open PanelsDCC Control, it asks you to log in.

If you do not yet have a PanelsDCC account, you can skip login and operate trains only. This is useful for testing everything works before you create an account.

Connection status at the top of the screen

After login (or not), the top of the screen shows the connection state to PanelsDCC Connect.

  • Ready: connected to PanelsDCC Connect, with a controller plugged in and detected.
  • No controllers: connected to PanelsDCC Connect, but no controller is currently connected or detected. Check PanelsDCC Connect setup.
  • Offline: this client device cannot connect to PanelsDCC Connect.

Offline is unusual when both are running on the Raspberry Pi, but it can happen on managed enterprise devices that block required local traffic. For best results, avoid enterprise-managed devices with strict security policies.

You can check this status at any time in the settings page of PanelsDCC Control.

Train control without login (quick test mode)

Without login, you will not have access to train creation with function maps, and accessory or panel operation will not be available.

Once you have an account and log in, PanelsDCC Control syncs your data from the cloud. You can then operate trains, accessories, and panels that you have configured.

To run trains without logging in:

  1. Open Trains.
  2. Click Select by DCC number.
  3. Enter the DCC number of the train you want to control.
  4. Control speed and direction, then use the function number buttons.

For layout and account setup, see Configuration.
