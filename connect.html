Set up PanelsDCC Connect

After installing PanelsDCC on your Raspberry Pi, this page walks you through opening Connect and attaching your command station.

For many users it can be as simple as plugging your controller into the Pi and turning it on. If your controller supports zero-configuration auto-detection and you only use one controller, Connect may configure itself and you might not need to change any settings.

Check the table below to see which controllers support zero configuration (auto-detection). Everything else needs manual setup in Connect.

Which controllers support zero-configuration auto-detection?

The Zero configuration column shows whether Connect can detect and set up the device automatically. Controllers marked Untested are currently unknown and may auto-connect or may require manual setup.

If you are using an untested controller, please read the testing page first.

Controller Implemented in PanelsDCC Connect Status Zero configuration Notes
Hornby Elite / XpressNet (xnet-elite) Yes Working Yes Auto-detects and should appear as connected when attached.
DCC-EX CSB1 (USB) (dccpp-ex-usb) Yes Working No Fully tested via USB.
NCE PowerCab (serial) (nce-serial) Yes Untested Untested Set up manually in Connect.
NCE PowerCab (USB) (nce-usb) Yes Untested Untested Set up manually in Connect.
DCC++ (Ethernet) (dccpp-ethernet) Yes Untested Untested Set up manually in Connect.

Controllers listed as untested are implemented but still need wider real-world validation.

Manual configuration and testing

Step 1: Access Connect

If you used hostname panels-dcc, open:

http://panels-dcc:9000/

If you chose a different hostname, use:

http://<hostname>:9000/

If you are on the Raspberry Pi desktop, you can also open the PanelsDCC Connect shortcut.

Step 2: Connect your controller

Connect your command station to the Pi, then follow the path that matches your controller:

  • Auto-detected device: it is configured automatically and should appear as connected.
  • Manual setup: enter the connection details yourself, then create the connection.

For manual setup, fill in:

  • Connection ID (example: elite1)
  • Controller Type (example: Hornby Elite / XpressNet)
  • Port (for serial/USB) or Host/Port (for network)
  • Baud Rate and Flow Control (for serial controllers)
  • Click Create Connection

Role assignment behaviour:

  • If you have one controller, it is auto-assigned to both trains and accessories.
  • If you add a second controller, it is auto-assigned as the accessories controller.
  • If you run two controllers, check role assignment each time you start up in Connect.

Step 3: Confirm everything works

Use Connect to verify the basics:

  1. Confirm your command station appears as connected and you can see some information about the manufacturer and version.
  2. Test one locomotive movement and function (where possible).
  3. Test one accessory (typically a point).

Once a train and an accessory behave as expected, you are ready to use PanelsDCC Control for day-to-day operation.
