Accessories

Points, signals, crossings, and other layout items are configured on the Panels DCC website. Each accessory has a name, a type that looks like the real thing, and a DCC number for every state you want to throw.

Open accessories on the Panels DCC website

Step 1: Choose a type

Click Add New Accessory. You first pick a type card — search or filter by category if the grid is long.

Point / Turnout
Colour signal
Four aspect
Semaphore
Open / closed
Level crossing
Custom

There is also a Turn Table type for accessories that use several DCC numbers. Custom is the catch-all for lights, motors, and anything without a dedicated picture.

For points and signals, pick the subtype that matches the geometry or aspect count (for example Point (Right up), 2 Aspect Home, Home Signal (GWR)).

Step 2: Name and picture

Give the accessory a short Name (required, up to 20 characters) — something you will recognise on a panel, such as “P1” or “Up home”.

The type image is used by default. You can upload your own picture or Choose from types to pick a different icon.

Step 3: Options and DCC numbers

Each row is one state the accessory can take (normal / switched, danger / clear, open / closed, and so on). For every row, enter the DCC number your command station uses for that state. Some types also ask for a direction.

Pre-built signals and points usually start with the right rows already; you fill in addresses. Custom and open/closed types let you Add Option if you need extra states.

Step 4: Save and repeat

Click Create Accessory. Add the other points and signals you will place on a panel next. You can also create an accessory later from the panel editor if you realise something is missing — see Panels.

Step 5: Macros (optional)

A macro is a named combination of accessories — for example “set the yard road” or “clear for the main”. Macros appear at the top of the Control accessories list so you can fire several commands in one tap.

This is not automatic route setting. Routes that follow trains and sensors will be documented in a later chapter.

Open macros on the Panels DCC website

  1. Click Create New Macro.
  2. Give it a name and, if you like, a short description.
  3. Select the accessories that belong in the group.
  4. For each state combination, choose the position each accessory should take.
  5. Save. Location is filled in later from which panels use those accessories — it may be blank until a panel exists.

Advanced: Table view (DCC audit)

You can skip this until you have enough accessories that addresses might clash. The card view is enough for a small layout.

On the accessory list, switch Card View to Table View (desktop). The table is organised by DCC number: one row per address, showing accessory name, type, panel(s), option, and direction.

Use it to see which addresses are used by what, and to spot two accessories sharing a number by mistake. Click a name in the table to open that accessory.
