Architecture of PanelsDCC

PanelsDCC is built as three closely-related components that work together to give you cloud-based configuration, always-on local control, and a simple connection to your DCC hardware.

PanelsDCC Design – Configure Away from the Layout

Manage your railway from the warm, dry places

PanelsDCC Design is a cloud-hosted configuration environment that runs in a web browser. You can build and refine your control system wherever you have an internet connection – not just in the loft, garage, or cold shed where the layout lives.

Use PanelsDCC Design to:

  • Configure trains and their functions (including icons and ordering)
  • Tap into a shared library of locomotives and images, so you don’t have to build everything yourself
  • Pick from an ever‑growing catalogue of function maps for ready‑to‑run models with many features – complete with sensible defaults and icons
  • Set up accessories, visual panels, routes, and combinations
  • Prepare sensor and automation behaviour (future)

Because configuration lives in the cloud, you can experiment, tidy up, and extend your setup at any time, then sync changes to the railway when you’re ready.

PanelsDCC Design is not a track planning tool; it is used to design the control system that operates your railway.

PanelsDCC Control – Your Digital Signal Box

Web-based control that keeps running

PanelsDCC Control is the local user interface used to run the railway. It runs on your Raspberry Pi and is accessed from phones, tablets, laptops, and desktops via a web browser.

Once installed and synced with PanelsDCC Design, PanelsDCC Control continues to work even if the internet connection drops – ideal for club rooms, loft layouts, and exhibitions.

The live state of the railway — trains, accessories, signals, and routes — is shared and kept continuously in sync across all connected devices. Every action is reflected instantly everywhere.

This enables a full “digital signal box” experience:

  • A large screen or two showing the overall panel and layout state
  • Tablets or phones used to drive individual trains
  • Devices dedicated to specific areas, yards, or stations
  • Multiple operators working seamlessly together at the same time

For club layouts and exhibitions, operators can even bring their own devices, instantly expanding the control surface. This is where the plural in Panels really matters.

PanelsDCC Connect – Interface to Your DCC Controller

PanelsDCC Connect runs on the Raspberry Pi and links PanelsDCC to your supported DCC controller.

Its job is simple:

  • Connect PanelsDCC Control to your DCC hardware
  • Translate commands to the command station reliably
  • Require only minimal setup so you can get running quickly

PanelsDCC Connect is the hardware interface layer – most of the time, you should barely need to think about it.

Why this architecture?

By separating PanelsDCC Design (configuration in the cloud) from PanelsDCC Control (operation on the Raspberry Pi) and PanelsDCC Connect (the DCC interface), the system supports both everyday running and more demanding environments.

With PanelsDCC you can:

  • Design and refine your control system in the cloud with PanelsDCC Design
  • Run with multiple operators on multiple devices using PanelsDCC Control
  • Display the layout state on large shared screens
  • Continue operating confidently even when connectivity isn't guaranteed, thanks to PanelsDCC Connect

This approach avoids the compromises of single-machine control systems, while still supporting the realities of club and exhibition layouts.
