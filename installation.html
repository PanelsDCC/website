Installation & Setup

Minimal setup, maximum resilience

PanelsD.CC is not a traditional desktop application. There's nothing to install on your devices, no operating system dependencies, and no single "control PC" that everything revolves around.

Cloud-Hosted, Not Installed

Your railway, everywhere you need it

PanelsD.CC is cloud-hosted and runs directly in a web browser. This allows the same system to work seamlessly across:

  • Mobile phones
  • Tablets
  • Laptops and desktops
  • Large screens and wall-mounted displays

Smaller devices are ideal for train and accessory control, while larger screens really come into their own for panels, where the full layout can be seen and operated at once.

Because configuration lives in the cloud, layouts can be designed, refined, and extended from anywhere — without needing to be physically connected to the railway.

A Simple Gateway to the Railway

The only local component required is a small gateway application, connected to a supported DCC controller.

The gateway acts as the bridge between the physical railway and PanelsD.CC:

  • It connects your DCC system to the Panels platform
  • It requires minimal configuration
  • It allows all devices to interact with the layout through a single, consistent interface

Crucially, the gateway is designed not just for connectivity, but for operational resilience.

While configuration and layout design remain cloud-based, the gateway supports offline operation. The core components needed to run the layout — panels, train control, and accessory control — can be hosted locally when required.

In practice, this means layouts can be prepared and configured in advance, then operated reliably at exhibitions or venues where internet access may be limited or unavailable — without changing how the system is used.

One Railway, Many Screens

Always in sync

PanelsD.CC is built around the idea that a layout is rarely operated from a single device.

The live state of the railway — trains, accessories, signals, and routes — is shared and kept continuously in sync across all connected devices. Every action is reflected instantly everywhere.

This enables flexible operating patterns:

  • A large screen showing the overall panel and layout state
  • Tablets or phones used to drive individual trains
  • Devices dedicated to specific areas, yards, or stations
  • Multiple operators working together at the same time

For club layouts and exhibitions, operators can even bring their own devices, instantly expanding the control surface. This is where the plural in Panels really matters.

Designed for Modern, Shared Operation

From home layouts to exhibitions

By separating configuration from operation, PanelsD.CC supports both everyday running and more demanding environments.

You can:

  • Design and refine your layout in the cloud
  • Run with multiple operators on multiple devices
  • Display the layout state on large shared screens
  • Continue operating confidently even when connectivity isn't guaranteed

This approach avoids the compromises of single-machine control systems, while still supporting the realities of club and exhibition layouts.
