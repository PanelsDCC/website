Getting started with PanelsDCC

Early access status: PanelsDCC is currently in Phase 1 – Controller Compatibility of the early access programme, focused on proving PanelsDCC Connect with a wide range of DCC controllers.

Read about the early access programme and how to get involved in testing →

PanelsDCC is not a traditional desktop application. There's nothing to install on your everyday devices, no operating system dependencies, and no single "control PC" that everything revolves around.

Instead, PanelsDCC follows a simple three-stage model that mirrors how you set up and run your railway:

  • Design – configure trains, accessories, and visual control panels in the cloud
  • Control – run the layout from a Raspberry Pi using any browser-equipped device
  • Connect – link the Raspberry Pi to your DCC controller

TL;DR – what you need

  • A Raspberry Pi on your layout, with PanelsDCC Control and PanelsDCC Connect installed.
  • A supported DCC command station, physically connected to the Raspberry Pi.
  • Your own devices – phones, tablets, laptops, desktops – with a modern web browser to connect to the Raspberry Pi over your network.
  • A PanelsDCC account so you can configure trains, accessories, and panels.

Installing PanelsDCC Connect and Control on your raspberry pi

Pre-requisites

  1. Raspberry PI 4 or later
  2. 16Gb micro SD card
  3. PC with micro SD card reader (SD card adapter)

Installing from blank SD Card

In this process it is recommended to follow the standard Raspberry Pi Imager process to install the latest version of Raspberry Pi OS (64 Bit) to the micro SD card. If you are intending to hook up a screen, keyboard and mouse to the raspberry pi, you will need to install the desktop version of Raspberry Pi OS.

Steps:

  1. Open Raspberry Pi Imager.
  2. Choose your Raspberry Pi device.
  3. Choose OS: Raspberry Pi OS (64-bit) (or Raspberry Pi OS (Desktop) if you are intending to hook up a screen, keyboard and mouse to the raspberry pi).
  4. Choose your SD card, then click Next.
  5. When asked to apply OS customisation settings, click Edit Settings.
  6. Go to the General tab and complete hostname, username/password, Wi-Fi, locale, and timezone.
  7. For hostname, we recommend panels-dcc so your URLs are easy to remember.
  8. Go to the Services tab and enable SSH if you want remote access. (for power users only)
  9. Go to the Options tab and enable a first-boot script / run command field (wording may vary by Imager version).
  10. Paste this command into that first-boot command field:
curl -fsSL https://panelsd.cc/install.sh | sudo bash
  1. Save settings and write the image.
  2. On first boot, give it a few minutes to complete installation.

After first boot, wait a few minutes for the install to complete, then continue with the post-install checks below.

Already running Raspberry Pi OS? Install with one command

If your Pi is already set up, use this command to install the latest releases of both PanelsDCC Connect and PanelsDCC Control.

  1. Make sure the Pi has internet access.
  2. Open a terminal on the Pi (or SSH in).
  3. Copy and run:
curl -fsSL https://panelsd.cc/install.sh | sudo bash

The script downloads the latest packages and installs everything automatically.

Post-install checks

If you set hostname to panels-dcc, use these URLs. If you chose a different hostname, replace it below.

  1. Open Connect: http://<hostname>:9000/
  2. Open Control: http://<hostname>/

Once you have confirmed the installation, continue to PanelsDCC Connect setup and connect your controller.

Using the Pi directly (screen, keyboard, mouse)

You can use PanelsDCC directly on the Raspberry Pi desktop if remote access is not available.

  • Plug a screen, keyboard, and mouse into the Pi.
  • After install, open the desktop shortcuts for PanelsDCC Connect and PanelsDCC Control.

This is especially useful for changing network setup in Connect, for example switching between home Wi-Fi client mode and offline hotspot mode.
